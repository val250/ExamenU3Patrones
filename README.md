# ExamenUnidad3_Patrones_ValeriaRosalesGomez  
## Valeria Rosales Gómez  

**Problema a resolver:**  
Sistema de monitoreo con alertas decorativas

</div>
El código presentado muestra una simulación de un proceso de 
elección de sistema de monitoreo. Se elige entre dos tipos de sistema;
para cocina o sala, posteriormente se cuenta con la opción de agregar alertas
adicionales con el patrón decorador y al final, al mostrar el resumen de la 
personalización del sistema se muestra también en inglés usando el patrón adapter.
